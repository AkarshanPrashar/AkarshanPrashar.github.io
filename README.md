## 🏛️ About This Project

This repository houses the source code for my digital architectural portfolio. Built with modern web technologies, it serves as a dynamic, interactive canvas to showcase my residential, civic, and conceptual projects, along with my working drawings and cinematic walkthroughs.

## ✨ Features

- **Spatial Narratives & Walkthroughs:** Cinematic video tours of projects, carefully lazy-loaded and optimized.
- **Interactive Working Drawings:** Embedded interactive flipbooks showcasing technical and structural execution.
- **Architectural UI Aesthetic:** A custom, blueprint-inspired design language featuring drafting grids, dynamic orientations, and smooth micro-interactions.
- **Performance Focused:** Built on **Next.js**, utilizing React's powerful capabilities to ensure quick loads and smooth scrolling.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Styling:** CSS Modules with a custom blueprint design system
- **Embeds:** Heyzine (Flipbooks) & Google Drive (Cinematic Walkthroughs)

## 📍 Getting Started

To run this portfolio locally on your machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/AkarshanPrashar/AkarshanPrashar.github.io.git
   ```
2. **Install dependencies**
   ```bash
   npm install
   ```
3. **Start the development server**
   ```bash
   npm run dev
   ```
4. **Explore**
   Open [http://localhost:3000](http://localhost:3000) in your browser.
